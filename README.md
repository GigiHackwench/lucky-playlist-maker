# Lucky Playlist Maker

A free, in-development playlist maker. Describe a scene or a feeling, such as walking home from school in mid-October, and get music that fits it. Tracks are sequenced by musical key (Camelot wheel) and tempo so transitions flow, and pairs that sit well together are tracked as "seams." Built by [GigiHackwench](https://github.com/GigiHackwench).

Tempo and key data provided by [GetSongBPM](https://getsongbpm.com).
